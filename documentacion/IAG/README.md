# Registro de uso de IA generativa (IAG)

Según los lineamientos del curso, todo uso de IA se documenta y cada integrante lleva su propio registro:

- `integrante_0X/r-ia-doc.md`: dudas y explicaciones (sin código).
- `integrante_0X/Uso_NN/`: cada sesión en la que la IA generó o modificó código, con `r-ia-dev-sNN.md`, `prompt.md`, `respuesta.md`, `codigo_antes.java`, `codigo_despues.java`, `cambios.diff` y `reflexion.md`.
- `plantilla/Uso_01/`: plantilla para copiar.

El uso de IA para **crear e integrar las pruebas es obligatorio**: cada integrante registra al menos el uso con el que se generaron las pruebas de su módulo.

Para copiar la plantilla (cambiar el número de integrante y de uso):

```bash
cp -r documentacion/IAG/plantilla/Uso_01 documentacion/IAG/integrante_01/Uso_01
```
